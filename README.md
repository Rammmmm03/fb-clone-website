# Facebook Clone Website

This project is a front-end clone of the Facebook website, developed as part of our Git and GitHub tutorial. The main goal of this project was to gain practical experience in web development while learning the fundamentals of version control using Git and GitHub.

The project recreates the basic look and layout of Facebook's user interface, helping me understand how to structure web pages, organize project files, and build a familiar social media-style design using HTML and CSS.

During this project, I practiced essential Git and GitHub operations, including initializing a repository, tracking changes, staging files, creating commits, writing meaningful commit messages, and managing project versions.

This project represents a step forward in my web development journey and helped strengthen my understanding of collaborative development workflows and version control.

**Technologies Used:** HTML, CSS, Git, and GitHub.

**Purpose:** Learning, practice, and hands-on experience with web development and version control.
